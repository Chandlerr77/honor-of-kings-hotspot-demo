# 王者荣耀热点营销工作台

只跟进游戏圈热点。流程：**采集 → 核验 → 匹配与爆点拆解 → 生成 → 人工审核**。

## 热点来源

| 来源 | 频率 | 说明 |
| --- | --- | --- |
| 上榜词条 | 每小时，免费 | 微博热搜、抖音热榜、B站热门中的游戏相关条目（关键词见 `game_profile.json`）。它们是破圈的游戏话题，热度由平台背书 |
| 游戏圈作品 | 每天 10:17，Apify 计费 | 抖音、小红书搜索“王者荣耀”的近 7 天高互动作品，内容需命中任一游戏关键词。抖音要求播放 ≥10 万；拿不到播放量时（Apify 免费版只返回样本）改为点赞 ≥1 万且评论 ≥100。小红书不公开播放量，按点赞 ≥1000 且评论 ≥50 判断 |

所有来源都经过黑名单过滤（`game_profile.json` 的 `blocklist`）：账号交易、代练、外挂等推广内容直接剔除。

B 站接口偶尔会触发风控（-352），这时该来源本轮跳过，状态栏会注明，其他来源照常采集。

## 分工

| 环节 | 谁负责 | 做什么 |
| --- | --- | --- |
| 核验 | 规则 + 大模型 | 由模型说明“这是什么事”，列出事实说法，联网逐条核对（DeepSeek、Claude 支持联网）。规则兜底：没有来源链接不算证实；有未证实的说法就不能判可信；与来源矛盾的判为不实 |
| 匹配 | 大模型 + 规则 | 对照 `game_profile.json`（设定、受众、禁忌）打 0–100 分，70 分起达标。同时拆解爆点：为什么火、火的形式、可借用的元素、还能热多久。存疑热点跳过这一步 |
| 生成 | 大模型 + 规则 | 每条达标热点出 2 版抖音脚本，每版必须借用一个爆点元素。规则检查：30–60 秒；分段首尾相接；5 秒内开场钩子；口播语速；话题标签；限制词。不通过就带着错误重写一次 |
| 审核 | 运营 | 复核存疑热点、确认选题、修改脚本、按原因驳回、确认终稿。每一步都记录操作人和时间 |

AI 结果按热点缓存在 SQLite（`analyses` 表），每条只分析一次。修改提示词后，改 `pipeline.py` 里的 `VERSION`，所有热点会重新分析。

## 两种运行方式

- **团队服务（推荐）**：`python serve.py`。审核状态、驳回原因和操作记录存在服务端，多人共享，两人同时修改时会检测冲突。详见 [Local.md](Local.md)。
- **GitHub Pages 静态站**：GitHub Actions 每小时采集免费来源、每天 10:17 加跑 Apify，然后发布快照。静态站不能保存共享状态，所以审核只存在访问者自己的浏览器里，只适合演示。

## 配置模型

在仓库 Settings → Secrets and variables → Actions 中配置下面任意一个 Secret；团队服务则设置同名环境变量：

- `DEEPSEEK_API_KEY`（当前选用）：默认模型 `deepseek-flash`，核验时使用 DeepSeek 自带的联网搜索（搜索本身不收费，只收 token 费）。需要先在 platform.deepseek.com 充值
- `ANTHROPIC_API_KEY`：使用 Claude，默认 `claude-opus-5-5`，核验时联网检索
- `GEMINI_API_KEY`（免费可用）：在 Google AI Studio 申请，默认模型 `gemini-3.5-flash-lite`，可用 Variables 的 `LLM_MODEL` 换成 `gemini-3.8-flash`。免费档没有 Google 搜索功能，所以不联网核验，事实说法转人工复核；另外，免费档的数据会被 Google 用于改进产品。遇到限流时会自动等待重试，没分析完的热点留到下一轮
- `DASHSCOPE_API_KEY`（通义）或 `MOONSHOT_API_KEY`（Kimi）：可以完成匹配和生成，但不联网，内容里的事实说法会转人工复核
- `ARK_API_KEY`（豆包）或 `OPENAI_API_KEY`：还需在 Variables 中设置 `LLM_MODEL`
- 其他兼容 OpenAI 的接口：Secret `LLM_API_KEY`，加上 Variables `LLM_BASE_URL` 和 `LLM_MODEL`

未配置模型时，系统照常采集，审核退回纯人工流程。

## 测试
